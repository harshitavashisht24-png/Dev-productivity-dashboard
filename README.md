# Developer Productivity Dashboard

This project analyzes developer productivity metrics such as:
- Cycle Time
- Lead Time
- Bug Rate
- Deployment Frequency
- PR Throughput

It provides actionable insights and suggestions using rule-based logic.

## Tech Stack
- React
- JavaScript
- JSON

## Features
- Color-coded metrics (Green/Red)
- Insight generation
- Suggestions for improvement

## How to Run
npm install
npm run dev
